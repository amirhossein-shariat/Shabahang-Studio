# Shabahang Studio (شباهنگ استودیو) — Project Brief for Claude Code

> این فایل خلاصه‌ی کامل تصمیم‌های گرفته‌شده در گفتگوی برنامه‌ریزی است. اول همه‌ی فایل را بخوان، بعد طبق بخش «کار اول» شروع کن.
> هر جا «تصمیم نهایی» نوشته شده، تغییرش نده. هر جا «باز» نوشته شده، قبل از ساخت از کاربر بپرس.

---

## 0. خلاصه‌ی یک‌خطی

یک **استودیوی کامل** (طراحی + دیجیتال + IT) که برای شرکت‌ها و کسب‌وکارها خدمات می‌دهد، با کارمندان خودش، یک سایت معرفی **لوکس، تیره و موشن‌دار**، یک پنل مشتریان و بعداً یک پنل داخلی تیم.

- **نام:** Shabahang Studio / شباهنگ استودیو
- **دامنه:** `shabahangstudio.ir` (در تاریخ ۱۴۰۵/۰۸/۱۵ معادل 2026-11-06 روی whois.nic.ir «no entries found» بود؛ یعنی ثبت نشده. کاربر باید ثبتش کند و ممکن است تا حالا گرفته شده باشد.)
- `spectrum.ir` گرفته شده بود و کنار گذاشته شد.
- **زبان سایت:** دوزبانه فارسی (RTL) + انگلیسی (LTR)
- **اولویت ساخت:** ۱) سایت معرفی ← ۲) پنل مشتریان ← ۳) پنل داخلی تیم (تا آن موقع با Notion/Trello)

## 1. معنی نام و کانسپت برند

- «شباهنگ» = ستاره‌ی سحری / ستاره‌ی صبح؛ «کسی که شب بیدار است». حس: بیدار، هوشیار، همیشه در دسترس (مناسب پشتیبانی و IT).
- کانسپت بصری: لحظه‌ی بین شب و سپیده، نوری که تاریکی را می‌شکافد، ستاره‌ی صبح.
- **شعار:** «وقتی همه خوابن، ما بیداریم» / Tagline انگلیسی: "Design, motion and IT, crafted for brands that never sleep."
- **حس کلی (تصمیم نهایی): لوکس و تیره.** نه فانتزی و نه سنگین. (کاربر صریحاً گفت طراحی نباید خیلی فانتزی و سنگین باشد.)

## 3. پروتوتایپ طراحی موجود

یک پروتوتایپ دو-بردی در Claude (Design canvas) ساخته شده:
- لینک: https://claude.ai/artifact/HxxuxPT1WCHiY7sfTgT7nX (خصوصی؛ فقط صاحب حساب می‌بیند)
- برد `Main`: هیرو + سه کارت خدمات. برد `Brand`: لوگو، پالت، فونت‌ها.
- **این فقط پیش‌نمایش حس و حرکت است؛ سایت نهایی از صفر در Next.js ساخته می‌شود.**

مشخصات هیروی پروتوتایپ (برای بازسازی):
- پس‌زمینه: گرادیان شعاعی `#14173A` → `#07091A`، درخشش افق (amber/violet) پایین صفحه با انیمیشن نفس‌کشی کند.
- ۱۸ ستاره‌ی کوچک با انیمیشن چشمک (twinkle، ۴ ثانیه، delay متفاوت).
- ستاره‌ی چهارپر طلایی در مرکز با pulse و glow.
- سه حلقه‌ی مداری نازک (۵۲۰/۷۶۰/۱۰۴۰ px) که در جهت‌های مختلف می‌چرخند (۷۰/۱۱۰/۱۶۰ ثانیه) و روی هر کدام یک نقطه‌ی نورانی.
- تیتر «شباهنگ» (Vazirmatn 900، حدود ۱۶۸px) با گرادیان طلایی و shimmer، زیرش «STUDIO» با letter-spacing زیاد، شعار فارسی، توضیح انگلیسی، دو دکمه (Start a project / View our work).
- ورود المان‌ها با `rise` (fade + translateY) به‌صورت پله‌ای.
- نوار بالا: لوگو، لینک‌های Work/Services/Studio/Contact، دکمه‌ی «LET'S TALK».
- `prefers-reduced-motion` باید همه‌ی انیمیشن‌ها را خاموش کند (در پروتوتایپ هست).

## 4. سایت معرفی — مشخصات فنی (تصمیم نهایی)

### Stack
- **Next.js (App Router) + TypeScript + Tailwind**
- **GSAP** (ScrollTrigger) برای انیمیشن اسکرول‌محور؛ Framer Motion فقط برای ترنزیشن‌های ساده‌ی کامپوننتی
- **react-three-fiber + three + @react-three/drei** برای پس‌زمینه‌ی ستاره‌ای
- i18n دوزبانه (fa/en) با routing مثل `/fa` و `/en`؛ `dir="rtl"` برای فارسی

### پس‌زمینه‌ی فضایی — انتخاب نهایی (رایگان)
- **ستاره‌ها:** `<Stars>` از drei (شیدر GPU، چشمک‌زن، لایسنس MIT). نمونه:
  `<Stars radius={100} depth={50} count={5000} factor={4} saturation={0} fade speed={1} />`
- **سحابی:** چند لایه گرادیان نرم بنفش/کهربایی پشت ستاره‌ی اصلی (CSS یا شیدر ساده‌ی خودمان؛ بدون وابستگی خارجی).
- **حرکت:** پارالاکس خیلی ملایم با ماوس و اسکرول.
- گزینه‌های کنارگذاشته‌شده: Interactive Galaxy، NebulaHero، Stellar Background (همگی پولی Framer)؛ CosmicNebula در 21st.dev (نیاز به API key، نصب رایگان محدود، لایسنس نامشخص).
- جایگزین رایگان احتمالی: **Galaxy از React Bits** (مخزن: «MIT + Commons Clause»، طبق صفحه برای استفاده‌ی تجاری آزاد). قبل از استفاده فایل LICENSE را چک کن. «warp jump»‌اش کمی پرانرژی‌تر از حس لوکس ماست.

### قواعد کیفیت (الزامی)
- سبک و سریع؛ نسخه‌ی موبایل سبک‌تر (تعداد ستاره کمتر، بدون افکت سنگین).
- سه‌بعدی/canvas را lazy-load کن؛ قبل از لود، یک گرادیان استاتیک نشان بده.
- `prefers-reduced-motion` را رعایت کن.
- کنتراست متن حداقل 4.5:1؛ لینک/دکمه‌ها واقعی (`<a>`, `<button>`)، فوکوس قابل‌دیدن.
- فونت‌ها را با `next/font` لود کن.
- کرسر سفارشی و ترنزیشن صفحه‌ها: **فقط اگر** عملکرد را خراب نکنند.

### صفحه‌ها (فاز ۱)
1. **خانه:** هیرو، خلاصه‌ی پنج ستون خدمات، نمونه‌کارهای منتخب، CTA
2. **خدمات و پکیج‌ها** (بخش ۵ همین فایل)
3. **نمونه‌کارها**
4. **درباره‌ی ما**
5. **تماس** (فرم + ایمیل سازمانی)

> متن‌های پروتوتایپ نمونه‌اند. ایمیل/تلفن در پروتوتایپ placeholder است: `[YOUR EMAIL] · [YOUR PHONE]`. محتوای ساختگی، آمار و نظر جعلی ننویس؛ جای خالی را با placeholder مشخص کن.

## 11. کار اول برای Claude Code

1. این فایل را کامل بخوان. کاربر را به فارسی مخاطب قرار بده.
2. پروژه‌ی Next.js (App Router، TypeScript، Tailwind) بساز، با i18n فارسی/انگلیسی و RTL.
3. توکن‌های رنگ/فونت بخش ۲ را در `globals.css` و تنظیم Tailwind بگذار؛ فونت‌ها با `next/font`.
4. کامپوننت `<Logo />` با ستاره‌ی placeholder و متن دوزبانه بساز.
5. **صفحه‌ی خانه:** هیرو را بر اساس بخش ۳ و ۴ بساز (drei Stars + سحابی CSS + ستاره‌ی مرکزی + حلقه‌ها + تیتر شباهنگ + دکمه‌ها)، سپس بخش خلاصه‌ی پنج ستون خدمات. انیمیشن ورود با GSAP.
6. اول فقط صفحه‌ی خانه؛ بقیه‌ی صفحه‌ها بعد از تأیید کاربر.
7. قبل از اتمام، `prefers-reduced-motion`، نسخه‌ی موبایل و Lighthouse را چک کن.
8. هر چیزی که نمی‌دانی (قیمت، تلفن، ایمیل، نمونه‌کار) را placeholder بگذار و جعل نکن.
