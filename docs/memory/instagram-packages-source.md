## Owner's requirement
Everything (headings, descriptions, prices) must be editable or removable in an admin panel; the number of cards can grow
or shrink; the owner sets the base price and the discount is applied from it. If the panel is not built yet, keep this in
memory and build it later. See `admin-panel.md`.
